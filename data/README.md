# data/ — базис XAUT ↔ XAU (и попутно PAXG)

Назначение: накопить наблюдения для проверки гипотезы «спред XAUT-перп против
золота расширяется до ~0.6–0.87% и возвращается к ~0.2–0.4%».

Статус: `DIAGNOSTIC_ONLY`. Торговых выводов из этих данных не делается.

Писатель: `../src/record_spread.py` (**только торговые площадки** — Variational +
Lighter; публичные read-only API, без счетов и без сделок). Бэкфилл минуток
Lighter: `../src/backfill_lighter_1m.py` → `lighter_{xau,paxg,xautspot}_1m.csv`
(свечи всегда можно дотянуть из API, поэтому рекордер их не дублирует).
Контекст и выводы: `../docs/xaut-xau-basis-context.md`.

В git лежат только семплы (`*_sample.csv`): полные файлы растут (опрос 60 с) и
воспроизводятся скриптами выше. `.gitignore` исключает всё остальное в этом
каталоге.

## Формат

Один файл на месяц: `spread_YYYY-MM.csv`, append, CSV с заголовком.
Минутки Lighter: `lighter_{xau,paxg,xautspot}_1m.csv` (`ts_utc,open,high,low,close,vol`).

Одна строка снимка = одна площадка за один опрос. Поля:

| Поле | Смысл |
|---|---|
| `ts_utc` | время записи (UTC, часы нашего процесса) |
| `venue` | `lighter`, `variational` (только торговые площадки) |
| `kind` | `perp` (ценовые поля), `spot` (XAUT/USDC), `funding` (только ставка) |
| `symbol` | `XAU`, `PAXG`, `XAUT`, `XAUT/USDC` |
| `mark`, `index`, `last` | цена маркировки / индекс / последняя сделка |
| `bid`, `ask` | лучшие цены (для `variational` — котировка OLP на размер 1k) |
| `funding` | текущая ставка фандинга |
| `funding_unit` | `per_8h` (за 8 часов), `annualized_decimal` (Variational: ×100 = % годовых) |
| `oi` | открытый интерес (для Variational — длинный OI) |
| `src_ts` | метка времени источника (если отдаётся) |

## Режим записи

Опрос раз в 60 с: Variational (XAUT, XAU, PAXG — единственный невосстановимый
ряд, истории у площадки нет) + Lighter (XAU perp m92, PAXG perp m48, XAUT spot
m2056, фандинг раз в 10 минут). Окна (пт 20:00 → пн 04:00 UTC, ежедневно
11:00–16:00 UTC) и триггер `|s| ≥ 50 bp` на любой из трёх пар против Lighter XAU
используются для алертов в логе, а не для изменения каденции. Минутки Lighter
берутся из нативных свечей API (см. бэкфилл выше), минутки Variational строятся
агрегацией 60-секундных снимков при анализе.

## Как считать спред

```text
s_bp = (lighter_XAU_mark − XAUT_mark) / lighter_XAU_mark × 10_000
```

«+» означает, что XAUT дешевле золота — именно это состояние автор идеи
называет расширением и в него покупает XAUT / продаёт XAU.
