- **Создан**: 2026-09-12. **Стабильная часть обновлена**: 2026-09-15 (volatile-состояние — только в `CONTEXT_HANDOFF.md`).
- **Статус**: RESEARCH_ONLY / DIAGNOSTIC_ONLY. Сделок нет, счетов нет — только публичные read-only API. Торговых выводов нет.

## 0. TL;DR

1. Это **не** арбитраж одного актива, а базисный трейд **между разными активами**: токен XAUT (Tether Gold) против золота XAU, через два перпетуала. Несёт базисный риск.
2. Норма спреда: **медиана +34…+37 bp** (XAUT дешевле золота). Заявленные автором «0,87%» за последние 62 дня на проверяемых парах **не наблюдались ни разу** (max 74 bp); хвост первой реконструкции оказался артефактом агрегатора (см. §6).
3. Действие (если оно есть) живёт либо в самом XAUT, либо в ноге Variational↔Lighter: обще-рыночный базис спокоен (симуляция по часовым убыточна при задержке ≥1 ч; PAXG-пара на одном Lighter за 7 дней ни разу не вышла за 50 bp).
4. Сбор идёт по схеме из §4–§5 (минутный рекордер) и §11 (тики рабочей пары); триггеры и критерии KILL — в §8. Текущее состояние — только в `CONTEXT_HANDOFF.md`.
5. С 2026-09-14 рабочая пара — **Lighter XAU↔PAXG** (один Lighter, исполнение ботом ~10 с, ищутся только входы): исполнимые спреды, скользящие нормы, тиковый сбор — всё в §11. Кросс-площадочная пара Variational↔Lighter (§2) — история и калибровка, не рабочая тактика.
6. С 2026-09-15 программа расширена до **мульти-площадочного скана**: 6 площадок (Variational, Lighter, Hyperliquid, Aster, Paradex, ApeX), активы — золото/серебро/платина/палладий/нефть/газ как кандидаты, BTC/ETH/SOL как контроль, 1000PEPE как пилот с хвоста. Треки оба: внутри площадок и между ними. Всё — в §12; Ostium исключён, медь пропущена (одна площадка).

## 1. Что за сделка

> Исходная идея: «Vari XAUT (Long) — Lighter XAU (Short) … на выходных было расширение до 0,87% … с текущих 0,6% можно набирать. Фандинг на расширении пассивный, на сужение насыпает, в спокойное время сужаемся до 0,2%».

- **Variational (Omni)** — perp-DEX с RFQ-моделью (цену даёт OLP — liquidity provider). Публичный read-only API без истории (см. §10).
- **Lighter** — perp-DEX с ордербуком, **taker fee 0%** `[ФАКТ, API]`. Рынки: XAU-PERP (92), PAXG-PERP (48), XAG (93), XPD (146), XPT (147), WTI (145), NATGAS (158), BTC (1), ETH (0), SOL (2), 1000PEPE (4); спот XAUT/USDC (2056) мёртв (см. §6 п.1).
- **Aster / Paradex / ApeX / Hyperliquid** — дополнительные площадки скана (§12): Aster — Binance-стиль API (стакан, свечи, фандинг); Paradex — только публичный bbo (стаканы XAU/XAG/XPT — заглушки, см. §12); ApeX — тикер+стакан, без XPT/XPD; Hyperliquid — PAXG-перп (+ BTC/ETH/SOL), XAUT/XAU нет.
- **XAUT** = Tether Gold (токен, обеспеченный физическим золотом, торгуется 24/7). **XAU** = золото, бенчмарк, на выходных **закрыто** — заявленный механизм расширения.
- Позиция дельта-нейтральна по золоту; прибыль = сужение спреда + фандинг.
- **Кто платит** `[ГИПОТЕЗА]`: тот, кому нужна срочная ончейн-экспозиция на золото, когда традиционный рынок закрыт/тонок, плюс контрагент по фандингу. Строгой «жертвы» нет — это риск-премия за ликвидность и базис.
- **Перпетуал** (для нем-FX читателя): бессрочный фьючерс без экспирации; якорь цены — фандинг, **терминального схождения нет**, базис может жить вечно.
- **Чем сделка НЕ является**: не арбитраж одного инструмента; не риск-фри (XAUT может неделями держать премию/дисконт: выкуп, доверие к эмитенту, регуляторика, конкуренция PAXG); две ноги на двух протоколах → маржа на обеих, ликвидация одной при живой второй = направленная позиция.
- **Базисный риск** (главный): текущая норма +34…+37 bp — это **цена рисков сегодня**, а не «ошибка». Режим смещается, если Tether меняет условия выкупа, случается кризис доверия (прецеденты USDT: депеги 10.2018, 05.2022, 08.2023 — `[ФАКТ]` по USDT, перенос на XAUT — `[ГИПОТЕЗА]`), делистинги/рост спроса.

Выводы: весь «край» — в первом часе (нужна минутная автоматизация); даже лучший случай ≈ +24 bp за 62 дня на номинал; 5–11 сделок за 62 дня → `N ≥ 100` достижимо за **1–2 года**. Заявленные автором «0,6% за вход» с этими числами не сходятся — либо исполнение за минуты, либо край в ноге Variational↔Lighter, а не в обще-рыночном базисе.

## 6. Снятые варианты и отозванные методы (журнал решений)

1. **Lighter XAUT-spot как нога — СНЯТ** (неисполним *и* неизмерим). Спот мёртв: 5 сделок/сутки (~$2046), нет bid/ask/глубины. Доказательство: во всех 430 минутах со «спредом» ≥50 bp объём спота был **ровно 0** (430/430) — «дислокации» это движение золота против замороженного принта. Свечи спота хранить можно, использовать как цену — нельзя.
2. **CoinGecko XAUT как источник истории — ОТОЗВАН.** Уровни коррелируют с биржами на 0.9988, но часовые доходности — на −0.03 (≈0): в каждый из топ-10 «пиков» Binance и Lighter были согласованы (20–67 bp), а CoinGecko печатал на 1–1.5% ниже. Вся первая реконструкция (медиана 37.1, «64 эпизода ≥87 bp», OU half-life 0.6 ч, кластеризация 11:00–15:00 UTC) — **артефакт, для решений не использовать**. Не повторять этот путь.
3. **CEX-опросы в рекордере — УБРАНЫ.** Binance/Bybit/Bitget/BingX/Hyperliquid служили только ретроспективе и разовому снимку 12.09 (расхождение оказалось обще-рыночным, не venue-специфичным). Решения — только по котировкам торговых площадок.
4. **Зеркальная сделка (вход на узком) — ОТКЛОНЕНА без отдельной предрегистрации**: прибыль ограничена (~20 bp до медианы), убыток нет (наблюдалось −150 bp), платится базис вместо его изъятия; керри +7.45%/год хвостовой риск не покрывает.
5. **Одна площадка — ПРИНЯТА как рабочая тактика 2026-09-14** (см. §11): Lighter XAU vs PAXG, тиковый сбор входов, исполнение ботом ~10 с. Снимает логистику двух марж ценой концентрационного риска. Вариант Variational XAU vs XAUT измеряется с 15.09 в скане (§12).
6. **Ostium — ИСКЛЮЧЁН 2026-09-15**: отдаёт цену оракула, а не стакан (нога неисполнима); плюс эксплойт оракула на $18 млн по сообщению прессы — для чтения данных помеха небольшая, для торговли был бы стоп-сигнал. Как ориентир не взят.
7. **Медь (COPPER) — ПРОПУЩЕНА 2026-09-15**: только Variational, пары нет — писать нечего. Появится на второй площадке — добавится одной строкой.
8. **Пилот с хвоста — ПРИНЯТ 2026-09-15**: 1000PEPE (4 площадки, глубина под $5k подтверждена замером; критерии: ≥3 площадки, ≥$5k с каждой стороны книги). Хвост шире — только если пилот покажет исполнимое, а не шум. Логика: тонкая нога + глубокий хедж = возможность; тонкая нога без хеджа = ловушка.
9. **Мёртвые книги Paradex — ЗАФИКСИРОВАНО 2026-09-15**: XAU (2178/17426), XAG (32/258), XPT (898/7187) — заглушки в разы от рынка, середины шум. PAXG — настоящий, но широкий (~1,5%) и мигающий. XPD-контракта нет вовсе.

## 7. Как мы сюда пришли (сжатая история)

- 12.09: исходная идея → живой снимок (спред +17.6 bp, керри −7.45%) → часовая реконструкция на CoinGecko (медиана 37 bp, «64 эпизода») → 9 вопросов → venues-нативная перепроверка → CoinGecko отозван, опорный ряд — Binance+Lighter (max 74 bp, +87 bp ни разу) → симуляция (край только в первом часе) → триггерный сбор.
- 13.09: минутки обеих ног (Lighter — нативные, Variational — только снимки) → PAXG-контроль (ноль эпизодов) → спот-нога снята (430/430) → упрощение рекордера до торговых площадок → перенос темы из SoSimple в `Hohlas/light` (с потерей сырого среза 12.09 — см. §4).
- 14.09: фокус — Lighter XAU/PAXG, бот ~10 с, только входы → стакан открыт без ключа → опрос 2 с vs поток (поток точнее, опрос снят) → порог 5 + счётчик норм 1/3/6/12/24 ч (см. §11).
- 15.09: кросс-опрос 3→6 площадок (Aster, Paradex, ApeX) + серебро → расширение на XPT/XPD/WTI/NATGAS, контроль BTC/ETH/SOL, пилот 1000PEPE (см. §12); Ostium исключён; опросник распараллелен (цикл 22,7→~5 с); ротация файла потока починена.

## 8. Критерии продолжения / KILL (предрегистрированы; относятся к кросс-паре Variational↔Lighter)

> Примечание 2026-09-14: рабочая тактика сместилась на пару Lighter XAU↔PAXG с ботом ~10 с (см. §11) — пороги ниже пересмотру не подлежат задним числом, гейты для новой пары предстоят отдельно. Правило длительности читается так: эпизод короче времени исполнения обеих ног = неисполним.

- 8 недель сбора без эпизода ≥87 bp на паре Variational↔Lighter → гипотеза не подтверждается → KILL/смена инструмента.
- Эпизоды есть, но медианная длительность < 5–10 минут при нашем измеренном лаге исполнения → неисполнима нашей инфраструктурой → KILL (уточнение правила «<30 мин»: неисполнима вручную и без доказательства; код укладывается в минуты, проблема — увидеть дислокацию на минутном опросе, риск частичного заполнения двух ног, adverse selection, автономность в выходные).
- N ≥ 100 эпизодов + гейты (PF ≥ 1.3 при BS_p05 > 1.0, ≥30 на сторону, стресс издержек 2x) → только тогда отдельная предрегистрация сделки. Торговых выводов до этого нет.

## 11. Тактика Lighter XAU↔PAXG: тиковый сбор входов (с 2026-09-14)

Рабочая пара — Lighter XAU-PERP (m92) против PAXG-PERP (m48), исполнение ботом ~10 с, размер 1 000 USD (~0,23 унции, 1 уровень стакана). Выходы не планируются, ищется только наличие входов.

- **Спреды исполнимые, не середины:** вход `(xau_bid − paxg_ask)/xau_bid`, выход `(xau_ask − paxg_bid)/xau_ask`, в bp. Цена круга ≈ 3–5 bp (разброс двух ног при комиссиях 0%). Порог — абсолютный `|спред| > X` от нуля, не приращение за шаг: медленный дрейф виден как рост абсолютного значения.
- **Норма — скользящая, не константа:** закрытие идёт по норме возврата, открытие — норма ± X. Нормы = усечённое среднее P10–P90 входного спреда равномерных сердцебиений (1/мин) за 1/3/6/12/24 ч. **Рабочий сигнал входа: `|спред − norm_1h| > X`** — абсолютный гейт `|вход| > 5` выродился 15.09 (рынок сидел ниже −5: срабатывал в 94% тиков за сутки); старшие окна — контроль смены режима.
- **Поток вместо опроса:** `src/stream_tick_lighter.py` (подписки `ticker/92`, `ticker/48`, клиент на стандартной библиотеке) точнее опроса (`src/record_tick_lighter.py`, снят 2026-09-14). Пишется только |вход|>X + буфер 5 с до/после + сердце 1/мин (`hb=1`); фильтр на входе только (выход структурно >2 bp — фильтр по нему писал бы всё).
- **Факты на 2026-09-14:** эпизоды ≥40 bp — ноль (тики, опрос, минутки); >5 bp — 16 эпизодов 0–170 с, пики 6–10 bp; значения ≥10 bp — одна иголка 1,6 с (≥14 bp — 0,2 с), ботом за 10 с не взять. Режим сползает: norm_1h −6,6 против norm_24h −4,3.
- **Факты на 2026-09-15 (22 ч тиков, 641 тыс. строк):** медиана входа −7,68, макс 18,14; эпизодов >10 bp — 528 шт, самый длинный 231 с; ≥40 bp — ноль. Режим качается (−1 → −5…−8 → ~0); норма 1ч впервые в плюсе (+2,7). Ротация файла потока починена (имя дня — на каждой записи; данные 15.09 до 18:25 UTC лежат в файле 09-14).
- **Ключ:** закрытый ключ счёта — только в переменной окружения, никогда в чат/код/git; для чтения — код `ro:...`; агент ключ не запрашивает и не показывает.
- **Файлы тиков (вне гита; схемы — здесь, а не в `data/README.md` — он не для агентов):** `data/tick_stream_xau_paxg.csv` — один файл без даты (с 15.09; раньше дневные, склеены): `ts_utc` (с мс), `xau_bid/ask`, `paxg_bid/ask`, `spread_entry_bp=(xau_bid−paxg_ask)/xau_bid×10⁴`, `spread_exit_bp=(xau_ask−paxg_bid)/xau_ask×10⁴`, `roundtrip_bp=вход−выход`, `case_gt` (1 если выше порога), `hb` (1 у сердцебиения); `data/tick_norm_ГГГГ-ММ-ДД.csv` — `ts_utc,norm_1h,norm_3h,norm_6h,norm_12h,norm_24h,n_hb`; снятый опрос `data/tick_xau_paxg_*.csv` — каждая строка опрос (скрипт оставлен).
